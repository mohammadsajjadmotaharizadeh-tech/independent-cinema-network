# شبکه سینمای مستقل — نسخه صفرهزینه MVP

این نسخه یک وب‌اپ فارسی و بدون وابستگی خارجی است و برای تست منطق ایجنت فیلم «ناگهان برمی‌خیزد» ساخته شده است.

## قابلیت‌های نسخه فعلی
- داشبورد «امروز چه تغییر کرد؟»
- پروفایل قفل‌شده فیلم
- رجیستری جشنواره‌ها
- تقویم شمسی اعلام نتایج
- حافظه تصمیم
- نگهبان حیثیت و ضدتکرار
- تنظیمات قوانین ایجنت
- نصب‌پذیری به‌صورت PWA و کار آفلاین

## اجرای رایگان روی کامپیوتر
در پوشه پروژه اجرا کنید:

```bash
python3 -m http.server 8080
```

سپس در مرورگر باز کنید:

`http://localhost:8080`

## هزینه فعلی
صفر. هیچ API، سرویس پولی، دیتابیس بیرونی یا کتابخانه خارجی استفاده نشده است.

## مرحله بعد
۱. اتصال رایگان به Supabase برای کاربر و دیتابیس واقعی.
۲. انتقال ۶۷ رکورد ارسال «ناگهان برمی‌خیزد» به دیتابیس.
۳. ساخت موتور قانون برای PASS / BLOCK / VERIFY.
۴. افزودن پایش روزانه نتیجه‌ها.
۵. بعد از اثبات عملکرد، افزودن هوش مصنوعی با مصرف کنترل‌شده.
