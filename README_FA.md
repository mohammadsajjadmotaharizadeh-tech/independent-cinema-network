# شبکه سینمای مستقل — نسخه آزمایشی پیشرفته

این نسخه شامل موارد زیر است:

- صفحه خانه سینمایی و اسلایدی با چرخش خودکار
- بخش «فیلم‌های ما» و نمایش پرونده فعال «ناگهان برمی‌خیزد»
- بخش «ورود فیلمساز» برای ورود نمایشی کارگردان به پرونده اختصاصی
- داشبورد کارگردان با دسترسی سریع به قسمت‌های مختلف فیلم
- پرونده فیلم با پوستر نمایشی، مشخصات مرجع و مواد پرونده
- جشنواره‌ها، تقویم نتایج، حافظه تصمیم، نگهبان حیثیت و تنظیمات ایجنت
- رابط کاملاً فارسی با ظاهر تیره، مدرن و سینمایی

## فایل‌های اصلی

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `sw.js`

## روش انتشار

همه فایل‌ها را در ریشه مخزن GitHub Pages قرار بدهید.
